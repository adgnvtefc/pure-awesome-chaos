Run the nightly build
Starts at 1:00 AM every night and runs until about 6:30 AM.
What this switch does

macOS has a built-in job scheduler called launchd. Turning this on writes a small settings file (a "LaunchAgent") that says "run this command at 1:00 AM every day", then tells launchd to load it. It runs as you, so no password is needed. Turning it off unloads the job and deletes the file. If a night is running, it stops that too.

The file:

The command it runs: . caffeinate -i -s keeps the Mac awake for as long as the command runs. --scheduled makes it skip the night if it starts more than 90 minutes late, which happens when the Mac was asleep at 1:00 and macOS runs the missed job on waking.

Wake the Mac for it
Your Mac sleeps when idle, and a sleeping Mac can't start the job. This wakes it at the start time.
What this switch does

This changes a system power setting, so macOS will show its own password dialog. This page never sees your password.

On runs:

  • sudo run as administrator (that's the password)
  • pmset macOS's power manager
  • repeat on a weekly schedule, not just once
  • wakeorpoweron wake it if asleep, turn it on if off
  • MTWRFSU which days: Mon Tue Wed thuRsday Fri Sat sUnday
  • 01:00:00 exactly the start time. Your Mac sleeps after 1 idle minute, so waking any earlier could let it fall back asleep before the job starts.

Off runs: . macOS keeps only one repeating wake schedule, so this clears it.
